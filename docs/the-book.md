The skills are based on the [AI Search Engine Optimization Guide](https://aichatwatch.com/books/ai-seo-guide/) by Eugene Mironichev. The book has four checklists with 25 items in total.

Every skill and every audit report credits the book. A report names the relevant PDF pages. If you ask a skill about its source, it gives the title, the author, and a link.

## What the book covers

| Topic | Skill |
| --- | --- |
| Content and reader intent (Chapters 3 and 6, Checklist 1) | [aicw-content](/skills/aicw-content) |
| JSON-LD (Chapter 7) | [aicw-jsonld](/skills/aicw-jsonld) |
| Crawler access and rendering (Checklist 3) | [aicw-audit](/skills/aicw-audit) |
| Submission to search engines (Chapter 7) | [aicw-submit](/skills/aicw-submit) |
| Mentions and citations (Chapter 8, Checklist 4) | [aicw-mentions](/skills/aicw-mentions) and [aicw-monitor](/skills/aicw-monitor) |

The skills follow the book where it applies. Where search providers changed their guidance, the skills label the change as a current correction. They do not promise ranking results.
