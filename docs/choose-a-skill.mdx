If you do not know where to start, use `aicw-optimize`. It covers all areas. The other skills each cover one area.

| If you want to | Use |
| --- | --- |
| Audit and improve a whole site | [aicw-optimize](/skills/aicw-optimize) |
| Check that pages answer what readers ask | [aicw-content](/skills/aicw-content) |
| Check or repair JSON-LD structured data | [aicw-jsonld](/skills/aicw-jsonld) |
| Check robots.txt, sitemaps, and rendering | [aicw-audit](/skills/aicw-audit) |
| See how AI assistants mention your brand | [aicw-mentions](/skills/aicw-mentions) |
| Compare results before and after a change | [aicw-monitor](/skills/aicw-monitor) |
| Prepare a sitemap or URL submission | [aicw-submit](/skills/aicw-submit) |
