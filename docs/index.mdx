AICW Skills help your AI agent do two jobs. The first job is to audit and improve a website for AI search. The second job is to check how AI assistants mention a brand.

A skill is a folder of instructions and helper scripts that an AI agent reads. You ask the agent in plain words. The agent uses the skill to do the work.

The skills are based on the book [AI Search Engine Optimization Guide](https://aichatwatch.com/books/ai-seo-guide/) by Eugene Mironichev. AI Chat Watch (AICW) publishes the skills under the MIT license.

## What you need

- An AI agent that supports skills, such as Claude Code or Codex.
- A website. Give the agent local files, a public URL, or a connected CMS (content management system).
- Node.js 22 or newer for the audit scripts.

The agent can edit a site only if it has access to the site source or CMS.

## The seven skills

| Skill | Use it to |
| --- | --- |
| [aicw-optimize](/skills/aicw-optimize) | Audit and improve a whole site. |
| [aicw-content](/skills/aicw-content) | Match page text to what readers need. |
| [aicw-jsonld](/skills/aicw-jsonld) | Check and repair JSON-LD structured data. |
| [aicw-audit](/skills/aicw-audit) | Check crawler access and rendering. |
| [aicw-mentions](/skills/aicw-mentions) | Check how AI assistants mention a brand. |
| [aicw-monitor](/skills/aicw-monitor) | Compare results before and after a change. |
| [aicw-submit](/skills/aicw-submit) | Prepare submissions to search engines. |

Each skill works alone. You can install one skill or all seven.
