---
title: Quickstart
description: Run your first website audit and your first AI mention check.
---

Do the [install](/install) first. Then open a new agent session.

<Steps>
  <Step title="Audit your website">
    Ask the agent:

    > Use aicw-optimize to audit my website for AI search. Show the findings and proposed fixes before editing.

    Give the agent your website URL, project folder, or connected site. If the target is not clear, the agent asks.
  </Step>
  <Step title="Read the findings">
    The agent reports each finding with evidence. It marks checks that it could not run. See [Reading reports](/reading-reports).
  </Step>
  <Step title="Approve the fixes">
    If you want changes, tell the agent which fixes to apply. The agent edits the site source or CMS that it can reach.
  </Step>
  <Step title="Check AI mentions">
    Ask the agent:

    > Use aicw-mentions to check how AI assistants mention my brand.

    The agent writes 3 questions that your customers might ask. It asks you once before it runs them.
  </Step>
</Steps>

<Tip>
An audit alone does not change your site or send anything to a search engine. The agent edits files only when you ask for edits.
</Tip>
